ValoCapture {VERSION}
====================

VALORANT の試合を自動で録画し、キル・デスなどのイベントから見返せるアプリです。


■ はじめかた
1. この zip を好きなフォルダに展開してください（デスクトップやドキュメントなど）。
   ※ zip を開いたまま中の exe を直接起動しないでください。
2. ValoCapture.exe をダブルクリックして起動します。
   タスクトレイ（画面右下）に常駐し、試合が始まると自動で録画します。
   インストールや管理者権限は不要です。

■ 初回起動時に「Windows によって PC が保護されました」と出たら
個人で作ったアプリでコード署名をしていないため表示されます。
「詳細情報」→「実行」で起動できます。
（展開前に zip を右クリック →「プロパティ」→「許可する」にチェック →「OK」
  としておくと表示されにくくなります）

■ 起動しない・録画が始まらないとき
Visual C++ 再頒布可能パッケージ（x64）が必要です。
次の URL から vc_redist.x64.exe をダウンロードしてインストールしてください。
  https://aka.ms/vs/17/release/vc_redist.x64.exe

■ 保存場所
  録画      : ビデオ\ValoCapture（設定画面で変更できます）
  設定      : %APPDATA%\ValoCapture
初期設定はコンペティティブのみ・1080p 60fps で、1 試合あたり数 GB になります（画質は設定画面で変更できます）。
ディスクが足りなくならないよう、設定画面の「動画の容量を制限する」で上限を決めておくのがおすすめです。
（上限を超えると古い試合から削除されます。☆ブックマークした試合は残ります）

■ アンインストール
ValoCapture.exe を削除し、必要なら上の 2 つのフォルダも削除してください。

■ 注意
・Riot Games 非公式のツールです。試合情報の取得に Riot クライアントの非公式 API を
  読み取り専用で使っています（ゲームへの書き込みや注入は一切しません）。
・自己責任でお使いください。
