# ValoCapture

VALORANT の試合を自動で録画し、キル・デス・アシストなどのイベントから見返せる Windows 用アプリです。

![ビューアのモックアップ](mockups/viewer.png)

- **自動で録画**：タスクトレイに常駐し、試合が始まると録画を開始、終わると停止します。操作は不要です
- **イベントから見返す**：試合後にキル・デス・アシストが録画のタイムラインに並び、クリックするとその場面から再生できます
- **容量を気にせず使える**：上限を決めておくと古い試合から自動で削除します。☆ブックマークした試合は残ります

## 動作環境

- Windows 10 / 11（64 ビット）
- VALORANT（Riot クライアントからサインインして使う通常の環境）

## はじめかた

1. **[最新版のインストーラー（ValoCapture-win-Setup.exe）をダウンロード](https://github.com/Kinefuchi1942/ValoCapture/releases/latest/download/ValoCapture-win-Setup.exe)** します
   - 過去のバージョンや、インストールせずに使う版（`ValoCapture-win-Portable.zip`）は [リリース一覧](https://github.com/Kinefuchi1942/ValoCapture/releases) にあります
2. ダウンロードした `ValoCapture-win-Setup.exe` をダブルクリックします。管理者権限は不要で、自分のユーザーのフォルダ（`%LocalAppData%\ValoCapture`）に入ります。必要なら Visual C++ ランタイムも一緒に入ります
3. インストールが終わると起動し、デスクトップとスタートメニューにショートカットができます
4. タスクトレイ（画面右下）にアイコンが出たら準備完了です。あとは VALORANT で試合をするだけで録画されます。録画中はアイコンが赤い丸に変わります

コード署名をしていない個人制作のアプリのため、次の警告が出ることがあります。

- ブラウザーで「一般的にダウンロードされていません」と出たら、「…」→「保存」（Edge では「保持する」）を選んでください
- インストーラーの起動時に「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」で進めます

### 新しいバージョンにするとき

起動時と 1 日 1 回、新しいバージョンがないか自動で確認し、あればダウンロードしておきます。準備ができると通知が出るので、タスクトレイのアイコンを右クリックして「バージョン ○○ に更新して再起動」を選んでください。録画中は更新できません。録画と設定はそのまま引き継がれます。

「更新して再起動」を選ばなかった場合も、次にアプリを起動したときに更新されます。

### 以前の ValoCapture.exe（1.4.2 以前）を使っていた場合

1.4.2 までの単体の `ValoCapture.exe` は自動更新に対応していません。タスクトレイから「終了」したあと、上の手順でインストーラーから入れ直し、古い `ValoCapture.exe` は削除してください。録画・設定・自動起動の設定はそのまま引き継がれます。

## 使い方

### 録画するモードを選ぶ

初期設定ではコンペティティブだけを録画します。タスクトレイのアイコンを右クリックし、「録画するモード」から録画したいモードにチェックを入れてください。

選べるモード：コンペティティブ、アンレート、スイフトプレイ、スパイクラッシュ、デスマッチ、チームデスマッチ、プレミア

### 試合を見返す

タスクトレイのアイコンを右クリックして「録画を見る」を選ぶと、録画の一覧が開きます。

- 左の一覧から試合を選ぶと再生できます。☆を付けた試合は容量制限で削除されません
- いらない試合は、見出しのごみ箱ボタン・一覧の右クリックメニュー・Delete キーで削除できます。動画とイベントはごみ箱に移るので、ごみ箱から元に戻せます（削除直後に出る通知の「元に戻す」でも戻せます）。録画中・イベント取得中の試合は削除できません
- イベント（キル・デス・アシスト・ラウンドの開始）は試合が終わってから追加されます。クリックするとその 3 秒前から再生します
- 再生速度は 0.25x / 0.5x / 1x / 2x から選べます
- 動画ファイルそのものは、右クリックメニューの「録画フォルダを開く」から開けます

### クリップを保存する

試合の一部を短い動画（MP4）として保存できます。保存先は録画フォルダの `clips` です（試合の一覧には出ず、容量制限で削除されません）。

- 範囲を決めて保存：再生位置を合わせて I キー（またはタイムラインの下の「始まり」）、O キー（「終わり」）で範囲を決め、「クリップを保存」を押します
- イベントから保存：右のイベント一覧でイベントを右クリックし、「前後をクリップに保存」を選ぶと、5 秒前から 3 秒後までを保存します
- 再エンコードしないので数秒で保存できます。そのぶん始まりは、決めた位置の直前のキーフレーム（1 秒ほど前まで）からになります
- 保存したあとの通知の「表示」で、保存したファイルをエクスプローラーで開けます

### 再生中のキー操作

| キー | 操作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← / → | 5 秒戻る / 進む |
| , / . | 0.1 秒戻る / 進む（コマ送り） |
| P / N | 前 / 次のイベントへ |
| ↑ / ↓ | 音量を上げる / 下げる |
| M | ミュート |
| F | 全画面（Esc で戻る） |
| I / O | クリップの始まり / 終わりを今の位置にする |
| Delete | 選んでいる試合を削除（ごみ箱に移動） |

### イベントの位置が動画とずれているとき

コンペティティブなどラウンド制のモードでは、VALORANT のログに残るラウンド開始時刻から試合ごとの補正値を自動で求めるので、通常は調整は要りません。デスマッチなどでずれている場合は、ビューアの「時刻補正」の − / ＋ で、イベントの位置を 0.1 秒ずつ前後に調整できます。

## 設定

タスクトレイのアイコンを右クリックして「設定…」を選ぶと、次の項目を変更できます。

| 項目 | 内容 |
| --- | --- |
| 起動 | Windows の起動時に自動で起動する |
| 録画の音声 | ゲーム音を録音する出力デバイス、マイクの音を録画に含めるかどうかとそのデバイス |
| 保存 | 動画の保存先、動画の容量の上限（GB） |
| アップデート | 新しいバージョンを自動で確認するかどうか、「今すぐ確認」 |

保存先を変えると、次の試合から新しい場所に録画します。それまでの録画は移動しません。

## 保存場所と容量

| 保存するもの | 場所 |
| --- | --- |
| 録画 | `ビデオ\ValoCapture`（設定で変更できます） |
| 設定 | `%APPDATA%\ValoCapture` |

録画は初期設定で 1080p・60fps（15 Mbps）、1 試合あたり数 GB になります。解像度・フレームレート・ビットレートは設定の「画質」で変えられます。ディスクがいっぱいにならないよう、設定の「動画の容量を制限する」で上限を決めておくのがおすすめです。上限を超えると古い試合から削除します（☆ブックマークした試合は残ります）。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 起動しない・録画が始まらない | [Visual C++ 再頒布可能パッケージ（x64）](https://aka.ms/vs/17/release/vc_redist.x64.exe) をインストールしてください（インストーラーで入れた場合は入っているはずです） |
| 試合をしても録画されない | そのモードが「録画するモード」に入っているか確認してください（初期設定はコンペティティブのみ） |
| 「すでに起動しています」と出る | タスクトレイ（隠れているアイコンの中も）を確認してください |
| イベントが表示されない | 試合が終わってから追加されます。しばらく待っても出ないときはビューアの再読み込みを試してください |

## アンインストール

タスクトレイのアイコンを右クリックして「終了」したあと、Windows の「設定」→「アプリ」→「インストールされているアプリ」から ValoCapture をアンインストールしてください。自動起動の登録も消えます。録画や設定も消したいときは、上の「保存場所」の 2 つのフォルダも削除します。
